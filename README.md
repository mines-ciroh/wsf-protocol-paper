# wsf-protocol-paper

This repository contains the reproducibility code for the WRR manuscript describing a standardized benchmark protocol for water supply forecast evaluation. It includes scripts and configuration files used to reproduce the manuscript figures, tables, and summary statistics.

The reusable benchmark protocol is maintained separately in the HydrometBench repository (https://github.com/mines-ciroh/HydrometBench/tree/main/water_supply_fcst). The frozen benchmark archive used by the manuscript is deposited separately in a citable data repository.

Preprint:

> *A Community Evaluation Protocol for Seasonal Water Supply Forecasting in the Western U.S.*
> Joshua T. Sturtevant, Andrew W. Wood, Chris D. Frans, Ian M. Ferguson, and Thomas C. Pagano
> *Water Resources Research* (in review)
> https://essopenarchive.org/doi/pdf/10.22541/essoar.15005900/v2
